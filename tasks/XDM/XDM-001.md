# XDM-001: X DM同期の失敗検出

X連携は成功しているがDMが受信されない。同期処理が外部API失敗を成功扱いする不具合を修正し、再試行で原因を確認できるようにする。

## Scope
- 外部API、トークン更新/保存、メッセージ保存の失敗を安全なコードで返す。
- APIルートで日本語の案内を返す。外部レスポンス本文や秘密情報は公開/記録しない。
- 認証、RLS、DB構造、自動取得頻度は変更しない。

## Verification
- 実処理をモックした回帰テスト、ルートテスト。
- typecheck、lint、build。
- Supabase反映後、所有者の手動同期で実APIの応答を確認する。実受信確認前に受信問題全体の解決を主張しない。
