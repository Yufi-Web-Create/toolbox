# APP-001 — Minimal Next.js Application

## Objective
Create the smallest valid Next.js application needed to verify the development pipeline.

This task exists only to confirm:
- Codex can implement within scope
- GitHub branch/PR workflow works
- Vercel can detect and preview a Next.js application
- the reviewer can inspect the PR and deployment

Do not implement product features.

## Preconditions
- ENV-000 completed
- Technical baseline approved in `docs/08_TECH_STACK.md`
- Architecture decisions in `docs/09_DECISIONS.md`
- Codex restrictions in `docs/10_DO_NOT_DECIDE.md`

## Technical baseline
Use exactly:
- Next.js 16.3.8
- App Router
- TypeScript
- Node.js 24
- npm

## Allowed changes
Codex may create or modify only files required for a minimal Next.js application and this task report.

Expected files may include:
- package.json
- package-lock.json
- next.config.*
- tsconfig.json
- eslint.config.*
- src/app/layout.tsx
- src/app/page.tsx
- src/app/globals.css
- public/* only if generated by the approved scaffold and actually needed
- task-reports/APP-001.md

## Forbidden changes
Do not:
- add Supabase
- add authentication
- add database code
- add API routes
- add external integrations
- add UI component libraries
- add state-management libraries
- add analytics
- add OpenAI
- modify docs/00-10 unless explicitly required by this task
- modify AGENTS.md
- modify GitHub Actions
- modify Vercel settings
- create environment variables
- create a custom design system

## Implementation method
1. Create a minimal Next.js 16.3.8 application in the repository root.
2. Use App Router and TypeScript.
3. Use npm.
4. Keep the UI intentionally minimal.
5. The home page must clearly display:
   - `toolbox development environment`
   - `APP-001`
   - `Next.js pipeline check`
6. Do not add product branding. `toolbox` is only an internal codename.

## Package policy
Only dependencies required by the minimal official Next.js application are allowed.

No additional application libraries may be added.

## Runtime
Add an engines declaration if appropriate so the project clearly targets Node.js 24.

## Tests and validation
Run:
- `npm install` or the scaffold's dependency installation
- `npm run lint`
- TypeScript validation if a separate script exists
- `npm run build`

If no separate typecheck script exists, report that fact. Do not invent unnecessary scripts unless required for the minimal application.

## Git workflow
- Create a task branch for APP-001.
- Do not work directly on `main`.
- One task = one branch = one PR.
- Create a draft PR targeting `main`.
- Do not merge the PR.

## GitHub communication
Before implementation, post `[CODEX:START]` on the APP-001 Issue.
If blocked, post `[CODEX:BLOCKED]` and stop.
When implementation and validation are complete, post `[CODEX:COMPLETE]`.

## Completion criteria
PASS requires all of the following:
- minimal Next.js app exists
- Next.js version is 16.3.8
- App Router is used
- TypeScript is used
- npm lockfile exists
- lint passes
- production build passes
- no forbidden libraries/features added
- task report exists at `task-reports/APP-001.md`
- draft PR exists and targets `main`
- no merge performed
- required GitHub reports were posted

## Out of scope
Everything except the minimal Next.js application and pipeline verification.
