# CI-001 — GitHub Actions quality gate

## Objective
Add the first GitHub Actions workflow so every pull request to main is automatically checked before review/merge.

This task is infrastructure only. Do not add product features.

## Preconditions
- APP-001 is merged into main
- Next.js minimal application exists on main
- Technical baseline in docs/08_TECH_STACK.md remains binding

## Required checks
The pull-request workflow must run:
1. npm ci
2. npm run lint
3. npm run typecheck
4. npm test
5. npm run build

## Approved implementation changes
Codex may:
- add a GitHub Actions workflow under .github/workflows/
- add a `typecheck` npm script using TypeScript
- add Vitest as the approved test runner from docs/08_TECH_STACK.md
- add the smallest smoke/unit test necessary to prove the test command runs
- update package-lock.json as required
- create task-reports/CI-001.md

## Workflow requirements
- Trigger on pull_request targeting main
- Use Node.js 24
- Use npm cache where supported
- Install dependencies with npm ci
- Fail the workflow if any required check fails
- Do not deploy from GitHub Actions
- Do not use secrets
- Do not run against Supabase or any external API
- Keep permissions minimal/read-only unless GitHub itself requires otherwise

## Forbidden
Do not:
- modify Supabase
- modify Vercel settings
- add authentication
- add database code
- add application features
- add Playwright yet
- add third-party CI services
- change Next.js/Node/npm versions
- merge the PR

## Git workflow
- One task = one branch = one PR
- Branch name: codex/ci-001 or equivalent task-scoped branch
- Create a Draft PR targeting main
- Do not merge

## GitHub reporting
Post to the CI-001 Issue:
- [CODEX:START]
- [CODEX:BLOCKED] if needed
- [CODEX:COMPLETE]

## Completion criteria
PASS requires:
- GitHub Actions workflow exists
- PR to main triggers it
- npm ci passes
- lint passes
- typecheck passes
- Vitest test command passes
- production build passes
- no secrets/external services used
- task report exists
- Draft PR exists and remains unmerged
